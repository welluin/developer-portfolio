# Developer Portfolio

Многостраничный сайт-портфолио разработчика программного обеспечения. Проект предназначен для презентации навыков, направлений разработки, реализованных проектов и контактной информации.

## О проекте

Сайт представляет собой персональное портфолио с современным минималистичным дизайном, светлой цветовой схемой и синими digital-акцентами.

Основная задача проекта — структурированно представить профессиональные интересы, технические навыки и практический опыт разработки.

## Основные возможности

- Главная страница с краткой информацией о разработчике.
- Раздел «Обо мне».
- Страница с направлениями разработки.
- Карточки проектов с описанием и изображениями.
- Информация о навыках и используемых технологиях.
- Раздел с этапами работы над задачами.
- Блок часто задаваемых вопросов.
- Контактная информация.
- Навигация между страницами сайта.

## Технологии

- **React** — создание пользовательского интерфейса.
- **JavaScript** — логика приложения.
- **CSS** — стилизация и адаптация интерфейса.
- **Vite** — сборка и запуск проекта.
- **Git** — контроль версий.

## Установка и запуск

Для локального запуска проекта необходим установленный Node.js и npm.

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/welluin/developer-portfolio.git
   ```

2. Перейти в папку проекта:

   ```bash
   cd developer-portfolio
   ```

3. Установить зависимости:

   ```bash
   npm install
   ```

4. Запустить проект в режиме разработки:

   ```bash
   npm run dev
   ```

5. Открыть адрес, указанный в терминале (обычно `http://localhost:5173`).

## Сборка проекта

Для создания production-версии выполнить:

```bash
npm run build
```

Готовые файлы сборки будут размещены в папке `dist`.

Для локального просмотра production-сборки:

```bash
npm run preview
```
